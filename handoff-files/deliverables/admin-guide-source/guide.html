1. The site in short

Aleph Review is a website of Hebrew reading games for students. The games are sorted like karate belts:

  • 10 belts, in this order: White, Red, Orange, Yellow, Green, Blue, Purple, Brown, Gray, Black.
  • 3 stripes in each belt. Each stripe has its own games.
  • A belt or stripe with no games shows Coming soon and can't be opened.

Students play without signing in. They only sign in with Google to see homework.

  • "Played" (the green badge at the top) counts the different games opened on that computer, in that browser. It needs no sign-in. A different computer or browser, or clearing the browser's data, starts again at 0.
  • Students earn a ★ star for each stripe where they played every game.

Admins (teachers) change everything on the admin page: games, words, the home page, homework and other admins. Nothing needs code.

2. Signing in

  1. On the site, click Admin at the top right.
  2. Click Sign in with Google and pick your school Google account.
  3. If your account isn't an admin, the page says so. Click Use a different account to try another one.

Two kinds of admins

Full adminsCan do everything, including adding and removing sub-admins. The list of full admins is kept in the Firebase security rules (Firebase console), not on the admin page.
Sub-adminsCan do everything on the admin page (games, words, homework, publishing) except manage admins. Full admins add them on the Admins tab.

To sign out, click Sign out at the top right of the admin page.

3. The top bar: Preview and Publish

Changes to games, words, How to play and the home page are a draft first. Students don't see them until you publish.

Status (next to the logo)Everything is published: students see what you see. Unsaved changes: you changed something that isn't live yet.
PreviewOpens the student site with your changes, so you can check them before students see them.
Undo all changesThrows away every change since the last publish.
Save & publishMakes your changes live for everyone. Students see them after they reload the page.
Your draft is kept in this browser.If you close the tab without publishing, your changes are still there next time. The page asks "You have changes that weren't published yet. Keep working on them?": OK keeps them, Cancel starts from the live site.
Homework, classes and admins save right away.They don't need Save & publish. Only games, words, How to play and the home page do.

4. Games tab

  • Pick a belt from the colored chips. The number is how many games the belt has.
  • Each stripe is a column. Games show in the order students see them.
  • Each row shows the game's picture, name and type. "Made here" means a game made on this site (it has a score and can be homework). A gray row with Hidden is hidden from students.

Moving games

  • Change the order: drag a game by its ⋮⋮ handle up or down.
  • Move to another stripe: drag it into another stripe's column.
  • Move to another belt: drop it on a belt chip at the top. Or edit it and change Belt and Stripe.

Editing a game

Click ✎ on a game. For a game made here you can change its name, theme, content, instruction, belt and stripe. You can also:

  • Hide this game from students: it stays on the admin page, so you can show it again later.
  • Delete game: removes it for good (after you publish).
  • Save and try it: saves and opens the game in a new tab so you can play it.

Remember: after changing games, click Save & publish.

5. Making a game

  1. On the Games tab, pick a belt and click + Make a game on a stripe.
  2. Type a Name and choose a Game type. The gray line under it says what the type needs.
  3. Pick a Theme: the picture behind the game (Meadow, Desert, Ocean, Space or Classic).
  4. Fill in the rows. Click + Add a row for more.
  5. Or use Paste many at once: one row per line, parts split by |. Pairs can also use =. Then click Add these.
  6. Optional: an Instruction line. It shows under How to play for this game only.
  7. Click Save and try it to play it, or Add game. Then Save & publish.
Paste many: examples Pairs: Alef = (the letter) or (letter) | Alef
Questions: Which one is Beis? | (right answer) | (wrong), (wrong)
Groups: Beis | (item), (item), (item)
Lines with gaps: put [ ] around the missing part, like (letter) (letter) [(letter)] (letter)

Games with more rows than one round holds are split into even rounds by themselves.

7. Wordwall games

The site first used games from Wordwall. Every Wordwall game has been copied into a game made here, with the same title, words and answers, in the same place. The Wordwall versions are hidden (still on the admin page, marked Hidden).

  • Wordwall can't tell the site a student's score, so Wordwall games can't be homework. That's why they were copied.
  • Where Wordwall showed a letter as a picture, the copy has the letter typed in. For some picture-only games the letters are a best guess; you received a separate list of those to check.
  • To bring a Wordwall game back: click ✎, untick Hide this game from students, Save, then Save & publish.

Adding a new Wordwall game

  1. On Wordwall, open the game, click Share, then Embed, and copy the code.
  2. On the Games tab, click + Add game on a stripe and paste it. The site fills in what it can, like the name and picture.
  3. Choose the Game type (it picks the How to play text), then Add game and Save & publish.

8. Words on the site

Every word students see can be changed here: the home page, belts and stripes, How to play, the stripe-done message, homework, the words inside games, and the footer.

  • Keep words short and simple. Students are kids.
  • To make a word bold, put two stars on each side: **Start**.
  • Words in curly brackets, like {n} or {belt}, are filled in by the site. Keep them.

9. How to play

Each game page has a How to play box with 3 steps. Step 2 comes from the game's type and is set here, one line per game type. A game's own Instruction (set when editing the game) is added under it.

10. Home page

Choose what shows on the home page:

  • Letter tiles: the colored letter tiles. Each one opens its belt.
  • Numbers row: games to play, games played and stars earned.

To change the home page's words (headline, buttons), use Words on the site.

11. Homework

Give a class games to do at home and see who passed. Homework uses only games made on this site (not Wordwall games, and not the four card games with no score).

Step 1: make a class

  1. On the Homework tab, click + New class.
  2. Type a Class name and paste the students' Google emails, one per line (or with commas). Import a file… takes a CSV or text file, like a Google Workspace export.
  3. Click Save. It saves right away.
Use the right emails.Students see only homework for the email they sign in with. It must match the email in the class.

Step 2: make homework

  1. Click + New homework.
  2. Type a Title, pick the Class, a Due date and the Passing score (for example 80%).
  3. Under Games, type in the search box and click games to add them. Use ↑ to change the order and ✕ to remove one.
  4. Click Save. The class can see it right away.

A game counts as done only when the student reaches the passing score. They can try again as many times as they like.

Step 3: see who did it

On the Homework tab, click Who did it next to a homework.

To change or delete a homework or a class, click Edit next to it.

What students see

  1. Students click My homework at the top of the site.
  2. They click Sign in with Google and use the email that's in their class.
  3. They see their homework, the due date, and each game. A game shows Done when it's passed.

Playing games never needs sign-in. Only homework does.

12. Admins

Only full admins see this tab.

  • Add sub-admins: paste teachers' Google emails (one per line or with commas) and click Add. Import a file… adds every email in a CSV or text file.
  • Remove a sub-admin with the Remove button next to their email.
  • Full admins are set in the Firebase security rules (Firebase console), not here.

Changes on this tab save right away.

13. What students see

  • Game pages have Previous and Next game buttons, a Full screen button, and a button back to the stripe.
  • Games made here show a score at the end. Outside homework there's no pass mark; in homework they see the passing score.
  • When a student has played every game in a stripe, they get a star and a short message.

14. Tips and fixes

If…Do this
Students don't see my changeClick Save & publish. Then reload the site (on a computer: Ctrl + Shift + R).
+ Make a game does nothingReload the admin page (Ctrl + Shift + R). If it asks to keep your unpublished changes, either answer works.
I made a mistake and want to start overClick Undo all changes (only for changes not yet published).
I want to check before students see itClick Preview.
A game should be gone for a whileEdit it and tick Hide this game from students (you can show it again later). Delete only if you won't need it.
A student can't see homeworkCheck their email is in the class exactly, and that they signed in with that account.
A game can't be picked for homeworkOnly games made on this site with a score can be homework. Copy the game as a game made here.
"Played" number looks wrongIt counts games opened in that browser on that computer. It's not the same on other computers.
A game reads aloud and I don't want itStudents can press the game's sound button. To stop it for everyone, ask for the game's reading aloud to be turned off.
The admin page says I'm not an adminClick Use a different account and pick your school account, or ask a full admin to add you.
Good habitsKeep words short and simple for kids. Try each new game with Save and try it. Publish when you're done, then check the site.
